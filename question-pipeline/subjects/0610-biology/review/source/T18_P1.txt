M|18.1.10|Which set contains only sources of genetic variation?|mutation, meiosis and random fertilisation|exercise, memory and training|diet, injury and sunlight warming the skin|respiration, digestion and sweating|Mutation creates new genetic changes and meiosis and random fertilisation generate new combinations.
